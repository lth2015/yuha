# YUHA 设计交付 v1.0

**YUHA / 羽花 / ユハ — 让心动，有回声。**

Logo 把一片被风翻起的花瓣，收进一个向上舒展的 y。界面采用暖白、墨黑和花瓣橙，以少量、短暂的动作回应创作。

## 从哪里开始

1. 先看 `YUHA_Logo_Board.png`：标志、字标和单色 / 应用图标变体。
2. 解压后用浏览器打开 `YUHA_Preview.html`：顶部可切换创作、生成中、结果、作品库，并检查「减少动态」。该文件已内嵌样式和 Logo，可以单独打开。顶部状态切换会重播对应的展示动效以便检查；正式产品的触发次数以规范为准。
3. 将 `YUHA_Brand_UI_Acceptance.md` 交给 Claude / Codex：包括页面结构、组件状态、11 条动效规格及实际产品验收表。
4. `assets/` 中的 SVG 是 Logo 母版；PNG 用于需要位图的场景。`tokens.css` / `design_tokens.json` 可供现有项目接入。
5. 阅读 `DELIVERY_QA.md`，区分本设计包已检查的内容和实际产品仍需验证的项目。

## 文件索引

| 文件 / 目录 | 内容 |
|---|---|
| `YUHA_Brand_UI_Acceptance.md` | 品牌、视觉、页面、动效、开发交接与验收 |
| `YUHA_Logo_Board.svg` / `.png` | Logo 展示板 |
| `YUHA_Preview.html` | 独立交互预览，无外部服务调用 |
| `assets/` | 横向、单色、反白、独立图形、字标和应用图标 |
| `tokens.css` / `design_tokens.json` | 颜色、形状、间距与动效常量 |
| `previews/` | 实际浏览器渲染的桌面与手机界面截图 |
| `preview_checks.json` | 设计预览的视口与基本交互检查结果 |
| `contrast_checks.json` | 关键配色的计算结果 |
| `DELIVERY_QA.md` | 交付检查记录与边界 |

预览不生成音乐、不播放示例声音、不付款、不扣费。它有意保留真实音频占位，避免把示意波形误认为产品能力。正式项目需另外实现预览以外的页面和服务状态。

此设计包替换旧项目的临时品牌和视觉基准，不替换已有业务、版权、支付和上线要求。默认采用浅色界面；完整深色主题不在 v1.0 范围内。

## 素材制作说明

Logo 的两块形面与四个字母为本次自绘 SVG 路径，没有外部字体依赖。界面采用系统字体栈；展示板位图渲染使用 Noto CJK，随包不分发该字体文件。图像生成制作的品牌氛围图已在对话中展示，以这套 SVG 为参考；它是展示花瓣、纸张与风的效果稿，生产使用以 SVG 母版为准。

名称与标志尚未完成正式商标检索；本次交付不作注册可用性保证。
