# Veo 场景 MV：可点击交互原型

Codex，2026-11-26。来源：[产品规格 v2](../../../AI_SCENE_MV_VEO_SPEC.md)。中文布局稿，供 Claude 实现时对照；不是正式页面，正式实现仍需中／日／英及完整 `check:ui`。

打开 [prototype.html](prototype.html)，可选择 8/15 秒、修改起点与风格、填写场景描述、编辑分镜并确认。顶部“查看状态”和“演示下一状态”是设计人员工具，用于演示排队、生成、核对未知结果、合成、取消、完成、失败、限额等十一种状态；不会真的提交任务。

原型没有音频、视频、API、费用、账号、持久化和供应商凭据。关闭或刷新页面会重置，离开返回只证明当前页面内存中的交互设计。下载／分享按钮特意不可用，不以占位画面冒充实测成片。CSP 禁止联网；示例名称、文字和画面均为合成设计资料。

## 可复现的浏览器检查

从仓库根目录，在仅限回环地址的文档服务上查看；不必启动应用、数据库或 worker：

```sh
python3 -m http.server 4317 --bind 127.0.0.1 --directory docs
```

另一个终端运行（使用仓库 Playwright 和系统 `/usr/bin/chromium`）：

```sh
node docs/agents/visual-previews/veo-mv/check-prototype.mjs
```

最终结果：[prototype-check.json](prototype-check.json)，退出码 0，16 项原型交互检查、44 个视图（11 状态 × 360/393/768/1280 px）。检测可见面板／操作元素超出视口、脚本错误、减少动态效果与外部 HTTP 请求；截图由相同脚本生成。此检查范围小于产品 `check:ui`，不证明完整可访问性、三语、真实媒体、后端幂等或实际预算安全。

首次通过 `file://` 打开被云端浏览器策略拒绝，改为上述本地 HTTP 文档服务后完整检查通过。没有更改浏览器策略，也没有访问外部生成服务。
