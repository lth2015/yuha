# Synthetic photo QA backgrounds

These two original backgrounds were generated with the built-in imagegen tool solely for the bright/dark overlay checks. They are fictional scenes without people, real user material, lettering or logos. The JPEG files are size/encoding conversions of the generated PNGs. They stay in this documentation directory and are not shipped as product assets. Production artwork is original code-native SVG geometry, with PNGs rendered from the editable sources in `sources/`.

## `sample-bright.jpg`

```text
Use case: photorealistic-natural. Asset type: synthetic bright-photo test background for YUHA video-overlay visual QA, not a production asset. Generate one original vertical 9:16 photograph: warm white linen curtain beside a sunlit pale wooden windowsill with one plain cream ceramic cup, soft late-morning light, neutral cream whites, detailed natural fabric, bright overall exposure, realistic quiet domestic still life. Entire scene is fictional. No people, faces, personal items, text, lettering, logos or watermark. No UI, no border, no overlay. Keep center fairly calm but with real photographic texture.
```
