第一批素材对应 `CODEX_VISUAL_REQUESTS.md` 的 1 至 7 项，基础版本为 master `531c8a1`，需求文本自 `9ec1601` 未变。第二批 X 广告图与视频封面不在本次交付中。

标签按 [Claude 的接入审查与方案一请求](https://github.com/lth2015/yuha/pull/90#issuecomment-7074325393) 修订。最初的 96px 固定文字区无法容纳实际日文和英文；当前接入应使用下面两张透明插画，由页面独立排版文字与底板。

## 素材与接入

| 文件 | 尺寸 | 接入位置与注意事项 |
| --- | --- | --- |
| `box.svg`、`lid.svg` | 各 160 × 150 | `HolidayOpening`。两个透明图层共用完整坐标系，盒盖单独向上移动即可拆开；图层应占满 object 的 160 × 150，不要再套用原占位 span 的 top、left、height，否则会重复偏移。 |
| `nengajo.svg` | 130 × 150 | 新年开场的完整静态贺状。独立太阳上升动画可改用同尺寸、同坐标的 `nengajo-card.svg` 与 `nengajo-sun.svg` 两个透明图层；不要在完整贺状上再画一个太阳。 |
| `tag-xmas-art.svg`、`tag-newyear-art.svg` | 各 110 × 120 | 首页接入用透明插画，只有礼盒或贺状，没有右侧底板。放在文字左侧，与 CSS 底板下边对齐。两张图的可见下缘均到 y 119，距画布下边 1px。文字和底板宽度由页面决定，不使用固定文字槽。 |
| `tag-xmas.svg`、`tag-newyear.svg` | 各 240 × 120 | 仅保留为最初构图参考，不用于接入；其中的 96px 固定文字槽不能承载当前三语言文案。 |
| `snow-1.svg` 至 `snow-4.svg` | 各 24 × 24 | `Snow`。白色带淡蓝边；可用 image 或 background-image 替换圆点。小尺寸建议先看清晰度再决定是否使用六角款。 |
| `fireworks.svg` | 128 × 128 | `Fireworks`。一次完整绽放，朱红、金、品牌橙；图中没有内嵌动画或脚本。现有组件控制出现、缩放与淡出。 |
| `xmas.png`、`newyear.png` | 各 1200 × 630 | 分享卡片透明边饰，按完整画布绘制，在标题和赠言之前叠加。 |
| `video-xmas.png`、`video-newyear.png` | 各 720 × 1280 | 分享视频透明边饰，按完整帧叠加，保持原有内容尺寸。 |
| 四个 `*-source.svg` | 与对应 PNG 一致 | PNG 的可编辑矢量源，可用于重新渲染，无需引入前端运行依赖。 |

素材位于 `apps/web/public/holiday/`。每张 PNG 的中央安全区 x 96 至 width − 96、y 112 至 height − 96 均完全透明。顶部角落和边框仍会绘制，接入后应检查实际 logo、文字、歌词与边框的关系。

透明标签的插画轮廓可直接叠在页面纸色或底板旁，不需要把右缘补成某种纯色。礼盒使用原有深橙渐变，最深边缘为 `#7E2A17`；贺状纸色为 `#fffdf8`，朱红细框为 `#c8372a`。页面继续使用深橙配白字、纸白配墨色的底板。预览中的 flex 排版仅用于展示分离后的素材与实际三语言文字，不替代 Claude 的产品 CSS。

贺状太阳上的两道浅色曲线是日轮纹理，随 `nengajo-sun.svg` 一起上升是设计意图，无需另做不动的波浪层。

**分享卡片的坐标不能直接套用现有函数参数。** 现有 `drawHolidayTrim` 对卡片传入的是右侧 570 × 630 区域；本次 PNG 是完整 1200 × 630。应在完整画布上绘制，或明确裁切后绘制，不能把整张 PNG 压进右侧区域。视频则已经传入完整帧。

素材不含文字、外链、字体、脚本、动画或真实用户信息。全部为本次原创矢量几何，PNG 从对应 SVG 渲染。未增加依赖，未修改组件、业务代码、CSS、价格、支付、季节判断或发布配置。

## 验证与预览

- `holiday-manifest.json` 记录每个素材的字节数、尺寸和透明通道。
- `holiday-preview.html` 展示盒身与盒盖组合、贺状、透明标签与四张边饰。标签使用当前产品的中日英六条节日问候，其余姓名和说明为虚构示意文字。字体与产品一样加载 M PLUS 2，网络不可用时回退到系统字体。
- `holiday-360.png`、`holiday-1280.png` 是该静态素材组合页在对应视口宽度下的截图，不是已接入产品的功能验收截图。
- SVG 大小、可解析性、无活动内容、PNG 尺寸与透明安全区已经检查。预览页检查图片加载和横向溢出。
- 标签修订预览在 360、393、768、1280 四个宽度下检查实际六条中日英问候语。M PLUS 2 的浏览器字体就绪检查通过，六条问候语在各宽度下均保持单行，文字未越出底板，标签未越出视口；360 宽下展示的 18 张图片全部加载。

Claude 接入后仍需完成需求中的真实页面 `check:ui`、三语言和对比度检查，以及系统减少动态效果下无动画的验收。素材本身不动，不代表接入组件已经遵守减少动态效果。
