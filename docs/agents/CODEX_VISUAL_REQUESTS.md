> 第一批是圣诞和新年（[HOLIDAY_SPEC.md](../HOLIDAY_SPEC.md)，12 月 10 日自动上线）。
> 现在页面上的节日元素是 Claude 用 CSS 画的占位，功能完整、能上线；Codex 的素材是把它做得更好看，不是补缺口。

## 所有素材共同的规矩

- **原创**：不用任何现成的圣诞形象、角色、字体图形或别家品牌的节日元素。不用 AI 生成素材里常见的「圣诞老人、驯鹿、雪人」，YUHA 的节日只有：雪、礼物、年贺状、朝阳。
- **配色**用页面已有的颜色（`apps/web/src/styles.css`）：
  - 纸色 `#f6f5f0`，墨色 `#20221f`，次要文字 `#6b6d66`
  - 品牌橙（petal）`#F46B45`，加深的礼物色 `#E8693F → #C2411F → #7E2A17`
  - 丝带米色 `#f4e6c8`
  - 年贺状：白 `#fffdf8`，朱红 `#d7402b`，描边 `#c8372a`
- **图里不放文字**。所有字都由页面按三种语言（中、日、英）排版；图里有字就只能是一种语言。
- **格式**：图形优先 SVG（干净、可缩放、文件小，单个 ≤ 20 KB）；照片感或渐变复杂的用 PNG/WebP，单个 ≤ 150 KB。
- **装饰性的**：页面会标 `aria-hidden`，所以素材不需要承担任何信息；拿掉它页面也完整。
- **放哪里**：`apps/web/public/holiday/`，文件名见下表。交付时附一张在 360 px 和 1280 px 宽下的效果截图。
- **公开仓库**：不放任何真实用户的名字、歌、订单或截图。示意用的名字用「小林 / ゆき / Mika」这类。
