## 布局

歌曲页现有照片／封面快速视频保持可用；其旁增加独立的「AI 场景 MV · 内测」卡片，只有 runtime 明确允许且歌曲所有者已注册时出现。不新增公共页面、互动计数或模型部署信息。

卡片从上到下为：用途与等待说明 → 可试听的歌曲选段 → 三个原创风格示意 → 可选画面描述 → 生成分镜。下一步就地显示可编辑分镜，用户确认后才调用 start。排队／生成／合成取代输入表单，保留离开提示、刷新与取消；完成后同一位置预览、下载、分享，显示服务端实际过期时间。

## 行为验收

- 选段优先使用保存时间轴的副歌，否则歌曲中段；默认约 30 秒、最长 32 秒，始终在实际音频范围内。试听使用同一个歌曲播放器，选段末尾停止。
- 新建、保存分镜、开始、取消、删除均有同步防双击；不自动重放失败写请求。恢复列表优先选正在执行的任务，不因新建草稿而把它隐藏。
- 页面初次加载从服务端列表恢复；当前任务在前台每 12 秒查询，后台暂停，回前台立即重新查询。旧响应不能覆盖新任务或已确认取消状态。
- busy 提供跨歌曲返回现有任务的入口；支持契约给出的 flat busy 和项目标准 error envelope。后端负责全用户唯一任务，前端禁用不替代该约束。
- 失败代码只映射固定文案，不回显服务端原话。失败／取消的内测任务不扣歌曲额度；不出现固定倒计时、零成本或未经验证的一分钟承诺。
- 下载与预览取新的所有者签名链接；短期链接 expiry 与成片保留期限分开。只显示成片实际 expiresAt；过期不提供失效的下载按钮。系统分享只在实际支持文件分享且文件已准备好时出现。
- feature 关闭、访客、非所有者不发场景 MV 请求。不写本地 prompt／照片数据，不发真实模型请求。
- 原创无文字风格图用页面字典排版名称；zh/ja/en；360/393/768/1280；减少动态效果无动画。
- 较新的任务失败不隐藏之前的成片；同一首歌可选择已有记录。切回标签页刷新服务端状态时保留未确认的分镜修改。
- 选段试听隔离为这首歌的单曲队列；改变选段即停止旧试听，到选段末尾／歌曲结束时退出试听状态，不会因重复时钟回调又恢复播放。

## 对照最新 T7 的联调项

实现期间只读核对了 Claude T7 `21dd4fd`，没有合入或改写其后端：

1. 草稿 detail/list 实际已返回 prompt，可正常恢复；创建、PATCH、start/cancel、列表、download、DELETE 的字段与客户端兼容。busy 的标准 envelope 与早期交接的 flat 形状都能导向现有任务。
2. 实际字段为 `othersInProgress`，不是早期文档的 `aheadOfYou`。页面不把“其他活跃任务”误称“排在你前面”，无真实队列位置时只显示阶段与不确定等待说明。
3. **本地媒体 MIME 待 Claude 修复**：`apps/api/src/routes/files.ts` 当前把所有非 WAV 文件都标成 `audio/mpeg`。T6 虽写入 `video/mp4`，local 路由未使用该信息；因此真实 local adapter 的 MP4 会被前端媒体检查拒绝。应按文件类型正确返回 MIME，并用实际签名 URL GET + 播放回归，不能只测拿到了 URL。S3 路径不使用这个 local 路由，其实际 CORS／类型仍需联调。前端没有把错误 MIME 或 HTML 强行改成视频来掩盖此问题。
4. T7 当前预设分镜正文是英文，界面本身已三语。若面向普通中／日文用户公开，需要确认是否给出本地化的分镜说明及其与模型 prompt 的关系；前端没有暗中调用翻译服务或改写服务端分镜。
5. T7 运行接通后仍需验证真正的任务恢复、取消后不提交后续镜头、所有者权限、唯一活跃任务、服务端 expiresAt／清理；以及真机保存／系统分享。员工预览与公开开关保持原状，本分支不授权上线。
