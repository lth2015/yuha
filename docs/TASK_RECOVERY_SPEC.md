# 任务找回 — 规格

> 2026-10-30。顺序里的第二项：私密问题反馈 → **任务找回** → 失败补偿记录。
> 目标是一句话：即使生成失败，用户也能看懂原因、找回任务、确认积分，并愿意再试一次。

## 现在缺什么

- **进行中的任务已经找得回来**：首页、创作页和作品库上有「进行中的生成」（`GET /v1/jobs`），
  刷新或重新登录后可以接着看。
- **失败、被拒绝、已取消的任务一结束就从页面上消失。** 如果用户在等待中关掉了页面，
  回来后既看不到它失败过，也看不到原因和额度去向，作品库里也没有它。
- **失败页上的额度说明是写死的文案。** 「额度已自动退回」「没有扣除额度」都没有读账本。
  按 CLAUDE.md 的规矩，「没有扣额度」这类承诺要读账本来证明。
- **失败后只能从空白重新开始。** 之前填的描述、歌词、风格和声音都要重新填一遍。

## 要做到什么

### 每个任务都带上账本上的结果

`JobView` 增加两个字段，都由服务端算出：

| 字段 | 取值 | 来源 |
| --- | --- | --- |
| `credit` | `held` 额度暂扣中 / `spent` 已使用 / `returned` 已退回 / `compensated` 原额度已过期，已补发 / `none` 没有用到额度 | 这个任务在 `ledger_entries` 里的 reserve / consume / release / compensate 记录 |
| `failure` | `refused` 内容被模型拒绝 / `timeout` 排队太久 / `cancelled` 你取消了 / `technical` 技术故障 / `null` 没有失败 | 任务的 `error_code` |

失败页、找回列表和作品库都只渲染这两个字段，自己不再推测额度去向。

### 找回没有完成的任务

`GET /v1/jobs/unfinished` 列出本人最近 30 天内没有生成作品就结束的任务（失败、被拒绝、
已取消），按时间倒序，最多 20 条。

- **首页和创作页**：在「进行中的生成」旁边列出 24 小时内结束的这类任务，点「查看」进入它的失败页。
  关掉页面后失败的任务，回来时能看到。
- **作品库**：「没有完成的生成」一节，列出 30 天内的全部，每条显示：
  - 描述或标题、时间（JST）；
  - 原因（`failure`）和额度结果（`credit`）；
  - 任务编号（完整 ID，联系客服时用）；
  - 「查看」和「再试一次」。

### 再试一次

`GET /v1/jobs/:id/draft` 把这个任务提交时的设置原样还给本人：描述、标题、歌词、风格、声音、
人声或纯音乐、能量、时长、公开范围、赠言。

「再试一次」打开 `/create?retry=<任务ID>`，用这些设置填好创作页，**不会自动提交**：
- 用户先看一遍、可以先修改（被拒绝的任务通常需要换个说法），再自己点生成；
- 生成前照常显示「将使用 1 首额度」；
- 新的提交用新的幂等键，是一个新任务；
- 原来写了一半的草稿不会丢：页面顶部提示「已填入上次的设置」，并提供「恢复我原来的草稿」。

### 失败页

| 部分 | 内容 |
| --- | --- |
| 原因 | 一句话说明原因，来自 `failure` |
| 额度 | 一句话说明额度去向，来自 `credit`。`returned` 时写「额度已退回」，`compensated` 时写「原额度已过期，已补发 1 首」 |
| 任务编号 | 完整显示，可以复制 |
| 按钮 | 「再试一次」（带上原设置）和「写一首新的」 |

### 顺带修复：声音选择

创作页选的声音（女声、男声、对唱、合唱）之前没有存进任务，所有歌都按「自动」生成。
现在已经存进任务，「再试一次」也会带上它。

## 不做的事

- 不自动重试，也不替用户扣额度。再试一次永远要用户自己按下生成。
- 不允许在列表里删除或隐藏任务。30 天后自然不再显示，账本记录不变。
- 不新增页面路由：找回列表放在已有的首页、创作页和作品库上。

## 验收

- 关掉页面后任务失败：回到首页能看到它，点进去能看到原因和「额度已退回」，这句话与账本一致。
- `credit` 的五种结果各有测试，都从真实的账本记录推出来，包括过期批次补发的情况。
- 别人的任务：`/v1/jobs/:id/draft` 和列表都拿不到，返回和任务不存在一样的 404。
- 「再试一次」填好的设置与原任务一致（包括声音和赠言），提交后是一个新任务，只扣一次额度。
- 原来写了一半的草稿可以一键恢复。
- 三种语言，360 / 393 / 768 / 1280 宽度（`pnpm check:ui`）。
