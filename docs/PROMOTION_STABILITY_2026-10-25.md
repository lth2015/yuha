# 社区推广前稳定性复核（2026-10-25）

入口为 `https://yuha.studio`，推广来源是 X。改动基于 `master@bcccdeedbabf4cb3fa1d521422331cd735267379`，分支为 `codex/promotion-stability`。

## 已修复

- API 路径被代理错误地返回 HTML/空正文时，不再当作成功的 null 数据传到页面，而是进入已有的请求失败提示。
- GET 遇到网络中断或 502/503/504，最多等待 500ms 后重试一次；连接与正文读取共用 15 秒截止时间。401、403、429、普通业务错误不自动重试。
- POST/PUT/PATCH/DELETE 的截止为 60 秒，给同步文本调用留空间；不自动重放写操作，不改变生成/购买的幂等键。超时不表示服务器没有接受请求。
- 旧请求返回 401 时，只清除它实际使用且仍然匹配的令牌；用户状态和额度同样按令牌核对，旧成功/失败响应都不能覆盖新会话。
- 临时读取失败保留当前会话最后确认的状态；更换登录会先清空旧额度和订阅，当前会话真正失效仍退出。后端仍是购买和额度预留的最终判断依据。
- 回到标签或恢复网络时重新读取用户、运行配置和额度；网络恢复不受刚发生的 focus 节流影响，隐藏页面仍不额外读取。
