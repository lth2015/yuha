# 迭代：让英文、日文用户找到 YUHA，并做完第一支照片 MV

> 产品负责人 2026-11-25。SEO、X 广告和产品转化共用落地页、素材和指标。
> 第一轮只做两个场景：**生日音乐礼物**、**旅行回忆**。涉及儿童照片的家庭场景以后再做。

**完成标准**：四个落地页（2 场景 × 英日）可被检索；iPhone Safari 与 Android Chrome 端到端验收通过；
试做→注册→认领顺畅；转化数据可核对；英日广告素材就绪。达到后再小预算投放。

## 来源命名（任务 4、7 共用）

`?src=<渠道>-<场景>-<语言>-<编号>`，例如 `x-birthday-en-1`、`x-travel-ja-2`。
没有 `?src=` 的访问，按首次落地页和来源网站记：从搜索引擎进入场景页记为 `seo-<场景>-<语言>`，其余不记。
