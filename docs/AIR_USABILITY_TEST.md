## 一、要回答的三个问题与通过线

| # | 问题 | 通过线 |
| --- | --- | --- |
| Q1 | 第一次触碰后，能否在 3 秒内听到令人愉悦的声音？ | ≥ 80% 的有效参与者 |
| Q2 | 是否愿意自主探索至少 20 秒？ | 有效参与者探索时长的**中位数** ≥ 20 秒 |
| Q3 | 体验结束后，是否主动希望把它变成一首完整的歌？ | ≥ 50% 的有效参与者**未经提示**点击「让它成为一首歌」 |

5～8 人的测试只用于早期可用性判断，**不是统计显著性结论**，报告中不得这样表述。

## 二、样本口径（冻结）

**谁算参与者**
- 自认为「不懂音乐」：不会看谱，并且没有系统学过乐器（累计不超过 1 年）。
- 没见过空气作曲，也没听人描述过它的玩法。
- YUHA 团队成员、参与过本项目讨论的人不算。
- 目标 5～8 人。人数在开始前定下（写在下面的记录表里），不因结果好坏增减。

**设备**
- 优先使用参与者**自己的手机**和自己常用的浏览器，保持他们平时的静音键和音量状态。
- 测试链接用 `…/artifact/WmbkMnN4GQr4AHtmCGSQfX#observe`（演奏页加 `#observe`）。参与者自己的手机必须能打开，所以测试前要把演奏页的分享设置改成「知道链接即可访问」。

**一场作废的条件**（只有这些，且必须写明原因）
1. 与产品无关的技术中断：网络断开导致页面打不开、来电或通知打断且参与者离开。
2. 主持人违反脚本给了提示（解释玩法、演示、提到「变成歌」）。
3. 参与者事后表示其实见过或听说过这个玩法。

**不算作废、计为未通过的情况**
- 因静音键、音量或浏览器原因没有声音。这正是产品要解决的问题。
- 参与者不知道要触碰、不想玩、很快放下。
- 页面在某台设备上出现产品本身的故障。

## 三、主持脚本（冻结）

1. 把打开好的页面交给参与者之前，主持人只说这一句：
   > 「这是一个声音小实验。你可以随便玩，玩到不想玩为止。我不会解释，结束后我们再聊。」
2. 测试过程中：
   - **不教、不演示、不提示**，不提「歌」「作曲」「回放」「分享」等任何功能。
   - 被问到怎么操作时，只回答：「你可以随便试试。」
   - 不评价参与者做得好不好。
3. 结束条件，满足任一即结束：参与者表示结束、放下手机，或者从交到手上起满 **5 分钟**。
4. 结束后，主持人点右上角那个很淡的「·」，把统计面板那一行原样抄进记录表，然后再问以下三个开放问题（不要追问引导）：
   - 「刚才感觉怎么样？」
   - 「有没有哪里让你困惑？」
   - 「用一个词形容你听到的声音。」
5. Q3 必须在问任何问题**之前**记录，因为问题可能让人意识到还有别的功能。

## 四、判定规则（冻结）

- **Q1 通过**：同时满足两点。
  1. 第一次触碰后 3 秒内，参与者明显听到了声音，比如表情变化、动作停顿或继续、说出口。
  2. 反应是正面或中性偏正面：笑了、说「好听」「哇」之类的话，或者在 5 秒内继续触碰。
  - 皱眉、说「吵」「难听」、立刻停下，都不算通过。
  - 没有任何可观察的反应时记为「未通过（无法判断）」，不推测。
- **Q2 时长**：从第一次触碰到参与者自愿停下的时间（主持人计时），中途主持人造成的打断从中扣除。统计面板里的 `played … s` 是手指实际按着、演奏在进行的时长，可以作为下限交叉核对。两者差距超过 10 秒时，在备注里说明原因。
- **Q3 通过**：统计面板显示 `make-it-a-song at … s`，并且主持人确认点击发生在任何问题和提示之前。

## 七、统计面板说明

演奏页地址末尾加 `#observe` 后，右上角会出现一个很淡的「·」，点开显示本次页面加载以来的数字：

```
first touch 1.8 s · played 51.0 s in 2 performance(s) (+0 too short) · replays 1 · make-it-a-song at 70.0 s · shares 0
```

| 字段 | 含义 |
| --- | --- |
| `first touch` | 页面出现到第一次触碰的时间 |
| `played` | 所有演奏的实际时长合计（包括不足 5 秒、没进入回放的那几次） |
| `performances` / `too short` | 完整演奏次数 / 不足 5 秒的次数 |
| `replays` | 点「回放」的次数 |
| `make-it-a-song at` | 第一次点「让它成为一首歌」的时间（从页面出现算起） |
| `shares` | 点「复制链接」的次数 |

这些数字只存在于这一次打开的页面里，不保存、不上传，关掉页面就没了。所以**每场结束时都要先抄下来，再关页面**。
