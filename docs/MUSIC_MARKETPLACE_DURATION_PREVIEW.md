# YUHA Music Marketplace：时长与试听设计（修订，2026-11-27）

本文只修订 Marketplace PRD 里**音乐时长与试听**这一部分，其余需求不变。原 PRD 不在仓库里（Drive 连接缺少权限，读不到），合并进原文要等原文到手。下面每一条都对照了仓库里现有的实现，标明已有、缺口和工程上的限制。

**设计原则：60 秒是 YUHA BGM 的起点，不是上限。** 既服务短视频创作者，也支持更长作品的发行和商业授权。

## 修订后的要求

| # | 要求 | 现有实现 | 缺口 / 限制 |
| --- | --- | --- | --- |
| 1 | **60 秒是核心起步规格。** 首批 20 首精品 BGM 原则上做不少于 60 秒的完整版本，同时满足流媒体发行和商业视频配乐 | 生成服务支持 60、120、180、240 秒 | 首批 20 首属于运营制作（BGM PRD 的 Phase 2），不是创作者自助的 15/30/60 秒 MVP。两者并存，不冲突 |
| 2 | **不限制最长时长。** 60 / 90 / 120 秒及更长都可以，按曲风和用途定长度，不强制截断 | 现在可选 30 / 60 / 120 / 180 / 240 秒 | **90 秒目前不能选**，要加到时长列表里（DGX 支持 10–240 秒之间任意整数秒）。**超过 240 秒**是当前引擎的上限（`deploy/dgx/music/server/app.py` 的 `MAX_DUR`），需要分段生成再拼接或换引擎，单独评估，**现在不能承诺** |
| 3 | **商城试听最多 60 秒**，可以暂停、拖动、重复播放；未授权的高品质原始音频要受保护 | 现在的 `previewUrl` 是**完整母带**的签名链接，拿到公开链接的人都能取到（`apps/api/src/routes/tracks.ts`） | **缺口**：需要单独的试听版本，最长 60 秒、低码率（建议 128 kbps MP3，可选加淡入淡出）。商城和公开页只给试听版的链接，母带只给所有者和已购买授权的人 |
| 4 | **短视频适配**：从完整曲目制作 15 / 30 / 60 秒版本，**挑最精彩、最适合短视频的那一段**，不机械截开头 | 已有导出功能，可指定起点、时长、淡出（`apps/api/src/services/exports.ts`）；分享视频已有"选副歌附近"的逻辑（`apps/web/src/lib/share-art.ts` 的 `clipWindow`） | 需要一个"精彩段落"选择器：BGM 没有歌词，靠能量、节拍密度和段落边界来选，运营可以手动改。默认选段要避开前奏和结尾淡出 |
| 5 | **购买后下载**：买了商业许可可以下载完整音乐，优先 MP3 和 WAV，以后可以扩展不同长度的剪辑版 | 授权购买已有（`market_license`，`track_licenses`），买家可以下载；WAV 导出有开关（`FEATURE_WAV_EXPORT_ENABLED`），目前关闭 | 打开 WAV 之前要先确认母带的位深和采样率；剪辑版做成同一授权下的附加版本 |
| 6 | **发行渠道适配**：各平台可能有最低时长、格式和 AI 音乐政策的限制，发行前按目标渠道的最新规则核对，不假设各平台要求一样 | 无 | 属于 BGM PRD 的 Phase 3。每个渠道建一张规则表，记录核对日期和来源链接；发行前自动校验时长和格式，政策条款由人工确认 |
| 7 | **数据结构**：一首音乐支持多个音频版本（完整母版、试听版、短视频剪辑版），共用同一个音乐资产 ID，分别记录时长、格式和授权范围 | `asset_versions` 已经是"一首歌多个版本"：`track_id` 加上 `kind`（目前只有 `master` / `quarantine` / `export`）、`format`、`duration_ms`、`clip_start_ms`、`clip_duration_ms`、`fade_out_ms`、`params_hash` | 增量改动：`kind` 增加 `preview` 和 `cut`（短视频剪辑版），再加一个 `license_scope` 列（`preview` / `personal` / `commercial`），写明每个版本可以给谁。**不需要另建资产体系**，`track_id` 就是音乐资产 ID |

## 落地顺序（建议）

1. **试听版和母带保护**：改动最小，风险最大的是现状——母带对公开链接可见，所以先做这一项。
2. 在生成时长里加上 90 秒。
3. 精彩段落选择器，加上 15 / 30 / 60 秒剪辑版。
4. 打开 WAV 下载，按授权范围控制谁能下载。
5. 发行渠道规则表（Phase 3）。

## 和商业许可核查的关系

商城出售商业许可的前提是模型许可核查通过，见 `docs/legal/MUSIC_LICENSE_AUDIT_2026-11-27.md`。核查结论出来之前，第 5 项的"商业许可"只做数据结构和购买流程，页面上不承诺商用权利。
